# Задачи для Trello

Обновлено 14.11.2026.

## Как перенести

1. Создайте доску и три колонки (в Trello они называются «списки»): «Готово», «Нужно сделать сейчас», «Предстоит».
2. Скопируйте блок строк ниже целиком, нажмите «Добавить карточку» в нужном списке и вставьте.
3. Trello предложит создать по карточке на каждую строку — согласитесь.
4. Описания задач — в TASKS.md: их можно вставить в карточку, если нужно.

Роль стоит в названии карточки. Если хотите цветные метки, создайте метки «AI-инженер», «Бэкенд», «Фронтенд», «Вся команда» и проставьте их вручную.
